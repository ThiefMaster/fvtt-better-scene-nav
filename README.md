# Better Scene Nav

This module improves the scene navigation dropdown in Foundry 13+ to be more usable when you have a
(very) large amount of scenes in it.

Instead of showing active scenes only on top of the list, it also keeps them in the expandable list
so you quickly see which scenes are nearby.

## Changelog

### v1.0.1
